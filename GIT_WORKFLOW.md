# Git workflow

The repository contains real staged commits created as the project was built. Do not falsify dates or rewrite history to make the work appear older than it is.

Suggested future commit messages when making your own changes:
- `docs: add lecturer feedback to changelog`
- `content: replace sample menu with confirmed café menu`
- `config: add confirmed WhatsApp number`
- `content: add confirmed collection location`
- `test: record Edge and Firefox browser checks`
- `deploy: update sitemap with live Netlify URL`
